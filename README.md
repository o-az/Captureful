# Captureful

Safari extension that captures scrolling screenshots of any scrollable area, including nested ones like chats, side panels and modals.

## Usage

1. Tap the Captureful button in Safari and scroll the area you want, or use Auto to scroll for you.
2. With "Confirm area" on, you can adjust the selected area (Bigger / Smaller) before capturing.
3. Press Stop, or let it stop at the end of the area. Then save as PNG or PDF, share, or copy.

Options (confirm area, auto-stop, output scale) are in the extension's settings page.
