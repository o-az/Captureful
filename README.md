# Captureful

Safari extension that captures scrolling screenshots of any scrollable area, including nested ones like chats, side panels and modals.

## Usage

1. Open the extension from Safari's page menu and start scrolling the area you want.
2. Captureful follows along and stitches each frame.
3. Stop by tapping the extension again, or let it auto-stop at the end of the area.

Options (confirm area, auto-stop, output scale) are in the extension's settings page.
